# Portfolio 2

قاعدة جاهزة لبناء بورتوفوليو باستخدام `Next.js 16` و`TypeScript` و`Tailwind CSS 4`.

## التشغيل

```bash
pnpm dev
```

ثم افتح `http://localhost:3000`.

## الأوامر المهمة

```bash
pnpm dev
pnpm build
pnpm lint
```

## الهيكل الحالي

```text
src/
  app/
  components/
  lib/
  sections/
  styles/
```

## أول حاجات تعدلها

1. عدل البيانات داخل `src/lib/site.ts`
2. غير محتوى الأقسام داخل `src/sections/`
3. أضف الصور والملفات الثابتة داخل `public/`
4. حدث `metadata` لو عندك دومين فعلي
