# Portfolio — Ziad Said

An interactive personal portfolio with a terminal you can actually type into.

**Live:** https://ziad-said-portfolio.vercel.app

## What's in it

- **Terminal emulator** — eight working commands (`about`, `projects`, `skills`, `experience`, `education`, `contact`, `help`, `clear`) that surface the same content as the page sections, so the site can be read either way
- **Boot screen** — the page loads like a machine starting up
- **Custom cursor** with a lens effect and a smooth follower
- **3D scene** rendered with Spline
- **Data visuals** built with d3
- **Light/dark theming** driven by design tokens rather than hard-coded colours
- Full SEO: generated sitemap and robots, plus Open Graph and Twitter card images

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Motion · Spline · d3 · shadcn/ui · deployed on Vercel with Analytics and Speed Insights

## Running locally

```bash
pnpm install
pnpm dev
```

Then open `http://localhost:3000`.
